¿Cómo funciona?

El IGV en Perú es 18% sobre la base imponible. Para agregar IGV, se multiplica la base por 1,18. Para extraerlo, se divide el total entre 1,18.

Total = Base × 1.18
Base = Total ÷ 1.18

Recuerda que en tus comprobantes de pago (facturas o boletas) debes distinguir entre el valor de venta (base), el IGV y el precio total.
